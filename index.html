GardenAI uploader

GardenAI uploader は、YouTube チャンネル「GardenAI」の運営者が、自分で制作した動画を自分のチャンネルへアップロードし、公開日時を予約するための個人用ツールです。

GardenAI uploader is a personal tool used by the operator of the YouTube channel "GardenAI" to upload their own videos to their own channel and schedule publication.

  • 利用者: GardenAI の運営者本人のみ / Used only by the channel operator
  • 使う機能: YouTube Data API v3 による動画のアップロード、サムネイルの設定、再生リストへの追加 / Uses the YouTube Data API v3 to upload videos, set thumbnails and add videos to playlists
